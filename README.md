# Dependencies

I have uploaded all the custom headers that i use in my cpp projects. I have not included the libraries that you can build yourself though. 

Here's a list of them with the link to download:
* [Glad](https://glad.dav1d.de/)
* [GLFW](https://www.glfw.org/download)
* [Assimp](https://github.com/assimp/assimp)
* [ImGUI](https://github.com/ocornut/imgui)
* [GLM](https://github.com/g-truc/glm)
